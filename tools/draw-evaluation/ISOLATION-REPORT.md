# 対象識別・品質判断の切り分け比較

2026-10-05。GPT-6.1 Sol / low、Codex subscription評価専用サブエージェントを使用。AI API呼び出しなし、本番変更なし。

## 比較条件

同じ12作品（明確な指摘8件、妥当な対照4件）を独立した3担当が評価する。旧得点・レビュー・他条件の評価は渡さない。

- prompt-v3新規実行：元の指示による通常の揺れを比較。
- prompt-v4：prompt-v3に対象識別の競合候補確認のみ追加。
- prompt-v5：prompt-v3に形・仕上がりの2/3/4/5境界確認のみ追加。

全条件でrubric-v2（4軸・0〜6整数）とscore-v2を固定。各候補は別の指示であり、prompt-v5をprompt-v4の後継として扱わない。UIの比較元は両候補ともレビュー済みprompt-v3初回。各担当はすべての軸を独立に評価するため、追加していない軸への変化も記録する。

## 解釈の制約

単回ずつ・同じレビュー集合の探索的比較。1担当が1条件を評価するため担当・文脈と条件の影響は交絡する。変化が人間の指摘方向でも改善確定や合格率とは扱わない。指摘のない対照でも変化を自動承認しない。候補を絞った後に未使用作品で検証する。散らばり・本番得点の変更は別段階。

再集計：`node tools/draw-evaluation/analyze-isolation.mjs`

### 対象識別

猫JW39は4→2で指摘方向へ変化し、新規v3とv5は4のまま。一方、うさぎKQXZとDJFGはv4でもお題らしさ4のまま。対象識別の代表3件のうち1件だけ指摘方向に動いた。猫KKPでは品質に対する指摘があったのに識別だけ3→2となり、熊AEEの妥当とされたお題らしさ5も4へ低下。総合点の低下だけを改善と判断できない。

### 形・仕上がり

猫KKPの形/仕上がり4/4→3/3、パンダ48V7の形4→3は指摘方向。ただし両方とも新規v3でも同じ品質段階に下がり、追加指示の効果は確認できない。熊AEEの4/4、狐8R1Eの3/3は変化なし。良い熊EFは人間が5/5でもよいとしたのに4/4→3/3へ逆方向。妥当な犬CRも形/仕上がり4/5→3/3、得点78.6→58へ低下。品質指示候補は採用を見送る。

### 元の指示の揺れ

元のv3の新規実行でも対照4作品すべてに段階変化があり、パンダ49→32、熊40→53などの差がある。初回v3からの平均絶対点差は新規v3で6.40、v4で5.77、v5で5.80点。単回の数字で優劣は決めない。

## 判断と次の検証

v4/v5をそのまま採用しない。全件の追加人間レビューはこの段階では求めない。残る中心課題は、指示の不足だけでなく対象の見え方と人間の品質境界への一致・再現性。次の候補は「お題を見せない対象認識」と「お題を与えた段階評価」を分け、段階4以上を付ける根拠が認識結果と整合するかを検証すること。これは入力・処理手順の新しい設計となるため、別の版と設計文書を用意して実験する。品質については3/4/5の一般的な境界例を整備してから未使用作品で確認し、今回の作品の期待値を評価入力に与えて合わせ込まない。

[評価ラボ](http://127.0.0.1:4317/)の条件選択で各版・runを確認できる。比較パネルはレビュー済みv3を表示する。v4/v5は別々の候補であって後継関係ではない。
