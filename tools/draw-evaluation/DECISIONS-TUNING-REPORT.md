# Decisions prompt tuning — 2026-10-09

既存17枚で9候補を試し、通常作品の明確な順位を優先する事前の選択基準でv4を固定、その後追加18枚を1バッチで確認した。合計10バッチ・171件、usageに基づく追加費用$0.078802。1バッチは対象セットを一つの指示で一巡する意味で、10 APIリクエストではない。上限は追加1ドルと10バッチの先着。既存鍵をメモリ経由で利用、秘密値は保存しない。

## 制約と選択

rubricの軸・0〜6段階・F換算・MAP採用は固定。対象名は通常のお題としてのみ入力。画像固有の答え、ID、教師モデル名、教師点、目標分布、正解例はプロンプトに含めない。一般的な識別・品質の境界を調整した。入力画像のSHA256を照合し、指示を各score質問に直接配置した。[公式仕様](https://developers.openai.com/api/docs/guides/decisions)のinput/質問の役割分担を確認。

候補選択はSolでsubject_match/form_coherence/finish_qualityがすべて3以上の開発10枚における、SolのF点差10以上の組について「逆転数＋0.5×同点数」が最小、同点なら全17枚の軸MAE、F MAEの順。追加18枚の値で選び直さない。両セットは過去に観測済みであり、追加セットも完全な未知テストではない。教師値はローカル集計だけに使用。原指示は既存結果を比較基準として保持した。
