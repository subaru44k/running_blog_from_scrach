# rubric-v2 初期比較（2026-10-05 JST）

人間レビュー23件（妥当8、要確認3、不適切12）で、中〜高評価の甘さと最高段階の条件不足が指摘されたため、旧版を保持して別版を作った。旧84評価、35件のレビュー履歴、画像・作品情報を取込前後で一致確認した。本番、既存スコア、人間レビューは変更していない。

## 新案

4軸、各0〜6の7段階: お題らしさ / 特徴の表現 / 形の整合性 / 仕上がりの質。旧「描き終わっている」だけで最高段階になる基準を変更。3〜4は通常の成立、5は明確に良い、6はその一つ下を超える可視的根拠を二つ示せる例外的な出来とする。線の震え・単色・写実性不足・無背景だけでは減点しない。最高段階の根拠はaxis_evidenceとして保存する。

score-v2: 段階変換0/10/25/45/65/82/100と重み40/25/20/15。お題0/1/2は15/35/55点上限。最大770種類の点数を算出できるが、モデルは最終点を出力せず、整数段階を決定論的に変換する。IDやランダムな微小値による同点解消はしない。

4軸で上位/中位の情報を増やし、7段階で普通の成立と優れた出来を分ける狙い。軸数・段階数・境界・prompt・配点を同時に変えているため、どの要素が効いたかはこの比較だけでは特定できない。

## 評価方法

指定GPT-6.1 Sol lowの新規サブエージェント3名が14件ずつ全42画像を実際に確認。旧点数、旧評価、人間レビューは渡さず、お題・画像・hash・新rubric/promptのみを使う。代表8作品を別の新規担当2名が追加評価し、計3回の独立反復、合計58 evaluationを追加した。反復対象は白紙、低得点、識別が曖昧な作品、旧版で高評価が否定された作品を含む。

実行はCodexサブスクリプション。OpenAI API・API key・外部推論の呼出0。model/effortを明示したspawn設定を記録し、snapshotは非公開のためunavailableとした。画像hash・全42件網羅性・型・バージョン・最高段階の根拠を検証してから取り込んだ。旧レビューをv2へコピーしない。現在v2人間レビューは未実施。

## 8作品×3回の予備安定性試験

最大点差の平均7.01点、全体最大17点。反復間の順位相関は0.922〜0.958。軸のペア一致率はお題75%、特徴75%、形83.3%、仕上がり66.7%。少数の広い得点帯の作品を選んでいるため、順位相関が高くても上位の近接順位が安定すると断定できない。v1の同条件反復はないので、v2がv1より安定しているという結論も出せない。

特にパンダ顔の作品PNHJは62/45/45点（最大差17）。ペンギンCNWCは65/52/65点（差13）。特徴の識別で段階が変わると点差が大きくなる。フクロウの上手い作品DMYVは71.8/62/65点。仕上がりと識別の境界に改善余地がある。

同点率改善だけでは採用しない。細かい得点差が反復の揺れより小さい場合、その順位を精密な差として扱えない。

## UI・検証

「評価版」でv1/v2を切り替える。新しい版を初期表示。初回42件を人間レビューし、反復16件は折りたたみから参照できる。旧評価とあなたの旧レビューはカードの比較パネルで開ける。旧版の要確認/不適切を新案でも優先確認するが判定は引き継がない。

Node test 9件成功: v1維持、v2全2401組合せの単調性/上限、版の混在拒否、最高段階の根拠、反復4軸統計、レビュー優先条件。別のdata-test-v2でv2レビュー保存/再読込保持、優先一覧からの除外、v1レビュー保持、反復2件表示をブラウザ確認。実データの人間レビューはテストで変更しない。

再集計: `node tools/draw-evaluation/analyze-v2.mjs`。初回のみの比較と反復統計を `data/v2-analysis.json` に保存する。UIの通常集計は全反復平均なので、この初回集計と値が異なる場合がある。

## 次の判断

まず新案の初回評価を人間が確認する。特に上記のパンダ2件・フクロウ・ペンギン・猫は、過大評価の改善と過小評価の有無を判断しやすい。レビューでは点数だけでなく4軸の段階と可視的根拠を確認する。必要に応じ、rubric境界を直す実験とscore変換のみを直す実験を分ける。今回のレビュー済み作品を設計に使ったため、独立holdoutによる検証、5〜10回の本格反復、近い順位同士の比較を経てから本番採用を判断する。
