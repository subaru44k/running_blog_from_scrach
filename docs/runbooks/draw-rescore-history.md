# 過去投稿の採点のみの移行

2026-10-11、ユーザーは過去月すべての99投稿（2026年2〜9月）を最新基準で再採点することを承認した。講評は保持する。API費用見積もりは約$0.031（3,154入力token/件、$0.10/100万token）。

`backend/draw/scripts/rescore-history.mjs evaluate <保存先の絶対パス>` は本番submitのsecret名を参照し、最新のDecisions・画像デコード・白紙判定・点数変換を再利用する。過去月の全レコードと画像を最初に保存し、画像SHA-256と採点結果を逐次保存する。失敗時は中断し、保存済み結果を再利用して再開する。講評APIは呼ばず、DynamoDBへの書き込みは行わない。

`node backend/draw/scripts/rescore-history.mjs apply <同じ保存先>` は全件の結果が揃った場合のみ、月単位のDynamoDB transactionで点数・採点メタデータ・既存ランキングキー・確定順位を更新する。全レコードがバックアップと一致することを事前確認し、更新時も旧点数と画像キーを条件にする。月内の同点順は既存createdAt/submissionId順を維持する。画像、講評、子ども用講評、講評状態、投稿日時、保存期限、アーカイブ対象の集合は保持する。SQS投入・月次cleanup・画像削除は行わない。保存先には元レコード、元画像、新旧比較、usage/費用、反映計画、検証結果を保存する。

過去の削除済み作品は復元できない。対象月の保存済み投稿が20件を超える場合や既存の順位索引がない場合は、この手順をそのまま使用しない。applyは更新対象以外の全フィールドの一致を読み戻して検証し、公開leaderboardも新順位・点数と比較する。
